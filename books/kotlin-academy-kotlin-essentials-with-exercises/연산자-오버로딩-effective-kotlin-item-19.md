# (Effective Kotlin Item 19) Kotlin - Operator Overloading

#### 연산자 오버로딩

* 코틀린에서는 `+` 연산자로 리스트에 원소를 추가할 수 있다. 똑같은 방법으로 두 문자열을 하나로 합칠 수 있다.
* 컬렉션에 특정 원소가 들어있는지 확인하려면 `in` 연산자를 사용한다.
* 이처럼 객체들 사이에서 연산자를 사용할 수 있는 이유는 코틀린이 제공하는 연산자 오버로딩 기능 덕분이다.

#### 산술 연산자

|표현식|컴파일러가 바꾼 형태|
|:----:|:----:|
|`a + b`|`a.plus(b)`|
|`a - b`|`a.minus(b)`|
|`a * b`|`a.times(b)`|
|`a / b`|`a.div(b)`|
|`a % b`|`a.rem(b)`|
|`a .. b`|`a.rangeTo(b)`|
|`a..<b`|`a.rangeUntil(b)`|

* 왼쪽 열을 오른쪽 열로 바꾸게 되는데 이 과정에서 코틀린 컴파일러가 매우 쉽게 처리해준다.

#### in 연산자

* 표현식 `a in b`는 `b.contains(a)`로 바뀐다.
* 부정으로 바뀌는 `!in` 연산자도 있다.

|표현식|컴파일러가 바꾼 형태|
|:---:|:---:|
|`a in b`|`b.contains(a)`|
|`a !in b`|`!b.contains(a)`|

#### iterator 연산자

* `iterator` 연산자 메서드를 가진 객체는 모두 for문으로 순회할 수 있다.
* `Iterable` 인터페이스를 구현한 모든 객체는 `iterator` 메서드를 반드시 지원해야 한다.
```kotlin
public interface Iterable<out T> {
    public operator fun iterator(): Iterator<T>
}
```
* `Iterable` 인터페이스를 구현하지 않고도 순회 가능한 객체를 정의할 수 있다.
* 대표적인 예시로 `Map`이 있다.
* `Map`은 `Iterable` 인터페이스를 구현하지 않지만 for문으로 순회할 수 있다.
* `iterator` 연산자가 코틀린 표준 라이브러리에서 확장 함수로 정의되어 있기 때문이다.

```kotlin
inline operator fun<K, V>
Map<out K, V>.iterator(): Iterator<Map.Entry<K, V>> = entries.iterator()
```
* 내부적으로 for문이 컴파일되어 생성되는 바이트코드는 객체의 `iterator`를 사용해 원소들을 순회하는 while문이 된다.

#### 등호와 부등호 연산자

* 코틀린의 동등성 비교 연산자는 두 가지이다.
* **참조적 동등성** : `===` 연산자로 확인하며, 피연산자가 모두 같은 객체를 가리킬 때, true를 반환한다. `===`와 `!==`는 오버라이딩할 수 없다.
* **구조적 동등성** : `equals` 메서드 또는 `==` 연산자로 확인한다. a가 널 가능하지 않을 때, `a == b`는 `a.equals(b)`로 바뀌며, 널이 가능하다면 `a?.equals(b) ?: (b === null)`로 바뀐다.
* 일반적으로 참조적 동등성보다 구조적 동등성을 자주 사용한다. `equals` 메서드는 커스텀 클래스에서 오버라이딩할 수 있다.

#### 비교 연산자

* 클래스에 따라 그 인스턴스끼리 순서가 자연스럽게 정해지는 경우가 있다.
* 자연스럽게 순서가 정해지는 클래스에는 Comparable 인터페이스를 구현해야 한다.
* 이 인터페이스는 두 객체를 비교해주는 `compareTo` 메서드를 정의하고 있다.
```kotlin
public interface Comparable<in T> {
    public operator fun compareTo(other: T): Int
}
```
|표현식|컴파일러가 바꾼 형태|
|:---:|:---:|
|`a > b`|`a.compareTo(b) > 0`|
|`a < b`|`a.compareTo(b) < 0`|
|`a >= b`|`a.compareTo(b) >= 0`|
|`a <= b`|`a.compareTo(b) <= 0`|

#### 인덱스가 있는 접근 연산자

* 컬렉션 안에 있는 원소를 얻거나 새로 설정하는 방법은 주로 두 가지가 있다.
  * 대괄호
  * get/set 메서드
* 자바의 경우 배열에서는 첫 번째 방법을, 다른 종류의 컬렉션에서는 두 번째 방법을 사용한다.
* 코틀린에서는 get/set 메서드가 곧 대괄호를 사용하는 연산자이므로 두 방법을 상호 변환하여 사용할 수 있다.

#### 증강 할당문

* 증강 할당문은 리스트나 문자열처럼 산술 연산을 지원하는 모든 타입에서 사용할 수 있다.
* 증강 할당문을 사용하려면 변수는 쓰기가 가능한 var이어야 하며, 연산 결과 타입도 변수의 타입과 호환되어야 한다.

|표현식|컴파일러가 바꾼 형태|
|:---:|:---:|
|`a += b`|`a = a + b`|
|`a -= b`|`a = a - b`|
|`a *= b`|`a = a * b`|
|`a /= b`|`a = a / b`|
|`a %= b`|`a = a % b`|

> **불변(Immutable) 객체와 증강 할당문(+=)**
>
> * 코틀린에서 `+=`는 재할당을 의미할 때가 많다.
> * 만약 a가 불변 객체이면, `a += b`는 기존 객체를 수정하는 것이 아니라, 기존 객체의 데이터를 복사해 새로운 객체를 생성하는 연산이 된다.
> * 컬렉션이 거대한 경우 불변 리스트에 `+=`를 남발하면 매번 새로운 리스트를 복사하는 비용 때문에 성능이 급격히 저하된다. 루프 내에서 대량의 데이터를 추가해야 한다면 `+=` 대신 `MutableList`의 `add()`를 사용하는 것이 좋다.

#### 단항 전위 연산자

* 단일 값 앞에 붙는 +, -, ! 기호 또한 연산자이다. 이런 연산자를 단항 연산자라고 한다.

|표현식|컴파일러가 바꾼 형태|
|:---:|:---:|
|`+a`|`a.unaryPlus()`|
|`-a`|`a.unaryMinus()`|
|`!a`|`a.not()`|

#### 증가 및 감소

* 전위 증가 : 변수 앞에 붙으며 변수의 값을 증가시키고 증가된 값을 결과로 반환한다.
* 후위 증가 : 변수 뒤에 붙으며 변수의 값을 증가시키고 증가된 전의 값을 반환한다.
* 전위 감소 : 변수 앞에 붙으며 변수의 값을 감소시키고 감소된 값의 결과를 반환한다.
* 후위 감소 : 변수 뒤에 붙으며 변수의 값을 감소시키고 감소되기 전의 값을 반환한다.

|표현식|컴파일러가 바꾼 형태|
|:---:|:---:|
|`++a`|`a.inc(); a`|
|`a++`|`val tmp = a; a.inc(); tmp`|
|`--a`|`a.dec(); a`|
|`a--`|`val tmp = a; a.dec(); tmp`|

#### invoke 연산자

* `invoke` 연산자를 제공하는 객체는 함수처럼 호출할 수 있다.
* 즉, 객체가 할당된 변수 뒤에 `()`를 적어주면 `invoke` 연산을 수행한다.
* 객체 호출 시 명시한 인수들은 `invoke` 메서드의 인수로 전달된다.
* `invoke` 연산자는 람다 표현식이나 유스케이스 객체와 같이 함수를 나타내는 객체에 사용된다.

```kotlin
class CheerUseCase {
    operator fun invoke(who: String) {
        println("Hello, $who")
    }
}

fun main() {
    val hello = {
        println("Hello")
    }

    hello()
    
    val cheerUseCase = CheerUseCase()
    cheerUseCase("Reader")
}
```
