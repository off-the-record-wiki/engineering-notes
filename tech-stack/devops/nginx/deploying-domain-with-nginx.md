# Nginx ‐ Deploying Domain with Nginx

#### Route53이란? 

* Route53이란 도메인을 발급하고 관리하는 서비스이다.

#### DNS(Domain Name System)란?

* IP 주소를 사람들이 일일이 기억하지 못한다.
* 문자를 IP 주소로 변환해주는 하나의 시스템을 DNS라고 한다.
